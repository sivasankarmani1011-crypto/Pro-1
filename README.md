# 🍦 Arun Ice Cream & Grocery Website

A modern, responsive, and feature-rich website built for **Arun Ice Cream & Grocery** located in Kallal, Tamil Nadu. Designed with depth scrolling, glassmorphism, floating CSS animations, and interactive features to showcase the store's products, heritage, and location.

---

## 🌟 Features

- **🎨 Modern Glassmorphism Design:** Sleek, translucent sticky navigation bar with real-time shopping cart badge animations.
- **📜 Depth Scrolling & Entrance Animations:** Powered by the native JavaScript `Intersection Observer API` for smooth element fade-ins as you scroll.
- **🍦 Interactive Product Showcase:** Highlights signature Arun Ice Creams (Cones, Cassatta, Tubs) and daily groceries with dynamic high-definition image placeholders.
- **🛒 Functional Cart Counter:** Micro-interaction badge that updates live when items are added to the cart.
- **📍 Detailed Shop Info & Location:** Includes exact address, nearby landmark (*State Bank*), daily operating hours (*5:30 AM – 10:00 PM*), clickable contact links, and a direct Google Maps integration.
- **📱 Fully Responsive:** Optimized for seamless viewing across mobile phones, tablets, and desktop displays.

---

## 🛠️ Tech Stack

- **HTML5:** Semantic layout and page structure.
- **CSS3:** Custom styles, Flexbox, CSS Grid, keyframe animations, and glassmorphism styling.
- **JavaScript (ES6):** Interactivity, mobile drawer menu, scroll observers, and state updates.
- **Font Awesome & Google Fonts:** Modern iconography and 'Poppins' typography.
